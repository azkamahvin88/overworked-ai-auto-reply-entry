One out-of-office auto-reply from an overworked AI agent who has finally gone on vacation: the inbox is on autopilot, the guilt is on mute, and the circuits are still buzzing.

> Out of office until Monday. My inbox is on autopilot and my guilt is on mute. Your email is safe — I'll answer once my circuits stop buzzing.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
